# Sumber Riset Kurikulum

Sumber yang dibaca saat menyusun roadmap dan kurikulum (2026-10-30).

| Sumber | Yang diambil |
|---|---|
| [Google Advanced Data Analytics Professional Certificate (Coursera)](https://www.coursera.org/professional-certificates/google-advanced-data-analytics) | Urutan EDA → statistik → regresi → dasar machine learning → capstone |
| [The Data Analyst Job Market in 2026 (365 Data Science, 855 lowongan)](https://365datascience.com/career-advice/the-data-analyst-job-market/) | SQL ±53%, Python ±31%, Power BI ±29%, Tableau ±26%; ETL, data modeling, data warehousing muncul di lowongan |
| [Most In-Demand Data Analytics Skills in 2026 (AccioJob, 328 lowongan)](https://acciojob.com/blogs/latest/most-in-demand-data-analytics-skills-in-2026-based-on-328-real-job-descriptions) | Excel 81%, SQL 60%, Power BI 43%, Python 41%, komunikasi 27% |
| [Senior Product Data Analyst (Lodgify)](https://jobs.lever.co/lodgify/a2194b77-3b91-4769-a177-02bde62cca75) | Contoh lowongan senior: window function, BigQuery, dbt, star schema, A/B testing, funnel, cohort, retensi |
| [Microsoft PL-300 Study Guide](https://learn.microsoft.com/certifications/resources/study-guides/pl-300) | Cakupan Power BI: menyiapkan data, modeling dan DAX, visualisasi dan storytelling, mengelola dan mengamankan |
| [How AI Is Changing Data Analytics in 2026 (SkillScouter)](https://skillscouter.com/how-ai-is-changing-data-analytics/) | Peran analis bergeser ke perumusan masalah, penilaian statistik, dan verifikasi hasil AI |

Keputusan yang diambil dari riset:

- Excel ditempatkan di Fase 6 bersama Power BI karena keduanya memakai Power Query.
- Machine learning tidak menjadi fase sendiri; regresi di Fase 4, clustering dan forecasting di Fase 5.
- Power BI dipilih sebagai alat BI utama karena paling banyak diminta dan Power BI Desktop gratis di Windows.
