# 🎁 portfolio/

Proyek portfolio, dibuka bertahap di akhir setiap fase. Satu folder per proyek, masing-masing wajib punya `README.md`.

| Folder | Proyek | Fase |
|---|---|---|
| `0_buku_resep_digital/` | Mini Project: Buku Resep Digital (CLI) | 0 |
| `1_laporan_eda/` | Laporan EDA | 1 |
| `2_studi_kasus_sql/` | Studi Kasus SQL | 2 |
| `3_pipeline_data/` | Pipeline Data End-to-End | 3 |
| `4_analisis_ab_test/` | Analisis A/B Test | 4 |
| `5_studi_kasus_ecommerce/` | Studi Kasus E-commerce | 5 |
| `6_dashboard_powerbi/` | Dashboard Power BI | 6 |
| `7_capstone/` | Capstone: Analisis End-to-End | 7 |

README setiap proyek minimal berisi: tujuan dan pertanyaan bisnis, data dan sumbernya, cara menjalankan, temuan utama, rekomendasi, keterbatasan, dan dua keputusan penting beserta alasannya.
