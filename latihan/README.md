| Folder | Isi |

| `0_python_dasar/` | Notebook dan file `.py` Fase 0 |

| `2_sql/` | File `.sql`, notebook, database latihan kecil |

| `4_statistik/` | Notebook statistik dan A/B testing |

| `7_ai_analytics/` | Notebook dan script AI |
